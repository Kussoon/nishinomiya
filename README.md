# 西宮市町名記憶ゲーム

西宮市の町名、町域、26コミュニティの位置関係を学ぶための、個人制作による非公式な学習用ウェブサイトです。

個人的に「どの町がどこにあるかを覚えたい」という目的から制作を始め、地域学習に役立ててもらうため、広告を付けずに公開しています。

公開URL：<https://kussoon.github.io/nishinomiya/>

## 収録内容

- コミュニティの場所当て
- コミュニティごとの町名チャレンジ
- 西宮市全域の町別地図

## フォルダ構成

- `index.html`：サイト全体のトップページ
- `communities/`：26コミュニティ別のトップページと2種類のクイズ
- `districts/`：6地区の町名チャレンジ
- `data/`：町域境界とコミュニティ対応データ
- `images/`：サイト内で使用する画像
- `scripts/`：複数ページで共用するプログラム

コミュニティ別フォルダには、西宮市公式サイトの掲載順に基づく2桁の管理番号を付けています（例：`04kawaragi`、`16najio`、`25yamaguchi`）。この番号は本サイト内の整理番号です。

既存のURLから移動したページには、新しいページへ自動的に移動する互換用ファイルを置いています。

## 地図データ

町丁・字等の境界には、次のデータを利用しています。

> 『国勢調査町丁・字等別境界データセット』（CODH作成）  
> 「令和2年国勢調査町丁・字等別境界データ」（e-Stat）を加工  
> CC BY 4.0  
> doi:10.20676/00000450

配布ページ：<https://geoshape.ex.nii.ac.jp/ka/resource/28204.html>

## コミュニティ区分

町名とコミュニティの対応は、平成15年度（2003年度）西宮市市民自然調査結果報告「コミュニティ町名一覧」を参考にしています。

参考ページ：<https://ikimono.leaf.or.jp/district/town/index.html>

現在の26地区に合わせて一部を独自に統合・調整しています。岡田山は「1〜3 広田、4〜7 上ヶ原」として扱っています。

本サイトでは、西宮コミュニティ協会等が作成した地図画像を転載していません。町丁境界データと町名一覧をもとに、区域を独自に構成・描画しています。
